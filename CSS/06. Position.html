CSS Position Property Demo

1. Static Position (Default)

Static is the default position. Elements flow in normal document order.

Static Box

This box follows the normal document flow. Top, bottom, left, right properties have no effect.

2. Relative Position

Relative positioning moves the element relative to its normal position.

Normal Box
Relative Box (moved 30px right, 20px down)
Normal Box

3. Absolute Position

Absolute positioning removes the element from normal flow and positions it relative to its nearest positioned ancestor.

This is a relatively positioned parent container.

Absolute Box (positioned at top-right)

4. Fixed Position

Fixed positioning removes the element from normal flow and positions it relative to the viewport. It stays in place when scrolling.

Scroll down to see the fixed box stay in place at the bottom-right of the screen.

Fixed Box (bottom-right corner)
