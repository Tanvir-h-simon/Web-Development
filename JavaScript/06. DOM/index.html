DOM: Document Object Model

When a browser loads an HTML page, it doesn't just display it - it converts your HTML into a live, programmable object that JavaScript can read and modify. That object is called the DOM (Document Object Model).

For example, the following HTML:


            <html>
                <body>
                    <h1>Hello</h1>
                    <p>World</p>
                </body>
            </html>

This becomes:

            Document // Parent of all nodes
                └── html // Root element
                    └── body // Child of html
                        ├── h1 → "Hello" // Child of body 
                        └── p  → "World" // Child of body
